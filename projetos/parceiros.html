ESTUDO DE CASO · PHP · MySQL · Tailwind · SheetJS

Portal de Parceiros

Portal com filtros, cadastro, importação de planilhas, exportação e acesso por perfis administrativo, financeiro e comercial.

O problema

Cadastros e informações de parceiros precisam ser consultados e atualizados por equipes com diferentes responsabilidades.

Minha participação

Desenvolvimento da interface, comunicação JavaScript com a API e operações PHP/MySQL de gestão.

Resultado funcional

O projeto centraliza consulta e manutenção de registros e separa as operações por perfil. Não há indicadores quantitativos de uso publicados.

Decisões e evidências técnicas

Interface em src/index.html; lógica em src/js/app.js; API em api.php; banco em db.sql. O README registra sessões, CSRF e ausência de suíte automatizada; a validação integrada requer banco de teste.
