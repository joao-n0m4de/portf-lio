ESTUDO DE CASO · PHP 8.1+ · REST · CSV/XLSX · Testes

Automação de Cancelamentos

A aplicação recebe CSV ou tabela colada, consulta a API e organiza os resultados para exportação.

O problema

Conferir serviços e reunir informações de cancelamento ou migração envolve consultas repetidas e consolidação de relatórios.

Minha participação

Desenvolvimento do processamento PHP, integração REST e interface de consulta, acompanhamento e exportação.

Resultado funcional

O fluxo reúne entrada, consulta e relatório, com cancelamento de processamento e exportação CSV/XLSX. Não há uma redução percentual de esforço medida.

Decisões e evidências técnicas

Integração em src/AtrixApi.php; regras em src/ReportService.php; XLSX em src/XlsxExporter.php. README documenta PHP 8.1+, cURL, variáveis de ambiente e composer test. A API real exige acesso autorizado.
