ESTUDO DE CASO · PHP · MySQL · JavaScript · PWA

Controle de Atualização de Chamados

Uma central reúne timers, alertas, responsáveis, transferências e registros de atualização.

O problema

Acompanhar prazos e repassar chamados entre analistas exige manter contexto e histórico em cada mudança de turno.

Minha participação

Desenvolvimento de interface responsiva, API PHP e persistência MySQL para o fluxo de acompanhamento.

Resultado funcional

O projeto permite consultar prazos e registrar atualizações em uma mesma interface. O ganho de tempo em produção não foi medido neste portfólio.

Decisões e evidências técnicas

Interface em sla.html; autenticação e persistência em sla.php; esquema em banco.sql; verificações estáticas em tests/security_regression.php. O teste estático não substitui testes integrados ou auditoria.
